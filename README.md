# Java Array Exercises

A collection of beginner-friendly Java exercises demonstrating one-dimensional and two-dimensional arrays.

## Exercises

| File | Topic |
| --- | --- |
| `Array1.java` | Calculate the total and average of subject marks |
| `Array2.java` | Read and print array elements |
| `Array3.java` | Store and display names with ages using parallel arrays |
| `Array4.java` | Analyze student grades: sum, average, highest, lowest, and passes |
| `Array5.java` | Calculate the sum of four integers |
| `Array6.java` | Find and count even numbers |
| `Array7.java` | Work with a two-dimensional array and calculate its main diagonal sum |
| `Array8.java` | Print negatives, sum positives, and count zeros |
| `Array9.java` | Produce a complete student-grade report |

## Requirements

- Java Development Kit (JDK) 8 or later
- A terminal or Java IDE

## Run an exercise

From the repository root, compile and run any exercise. For example:

```bash
javac src/Array4.java
java -cp src Array4
```

## Skills demonstrated

- Creating and initializing arrays
- Reading user input with `Scanner`
- Iterating with `for` and enhanced `for` loops
- Calculating totals, averages, minimums, and maximums
- Filtering and counting values
- Working with two-dimensional arrays
